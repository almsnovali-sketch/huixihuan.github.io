1. Краткое повторение грамматики

Конструкция Значение Пример
一点（儿） Немного; чуть-чуть 我想休息一点儿。
Я хочу немного отдохнуть.
先……然后…… Сначала…, затем… 我先吃早饭，然后上班。
Сначала я завтракаю, затем иду на работу.
喜欢 + глагол Любить что-либо делать 我喜欢看书。
Я люблю читать.
会 + глагол Уметь что-либо делать 我会做饭。
Я умею готовить.
都 Все; оба; все вместе 我们都喜欢看电影。
Мы все любим смотреть фильмы.
Важные нюансы
  • 一点儿 обозначает небольшое количество или степень: 学习一点儿汉语 — немного позаниматься китайским.
  • 先……然后…… помогает выстроить последовательность действий.
  • 喜欢 выражает предпочтение, а 会 — приобретённое умение.
  • 都 обычно ставится перед глаголом или прилагательным: 我们都喜欢看电影。

2. Упражнения на 一点（儿）

Упражнение 1. Собери предложение

Составь предложения из предложенных слов.

1. 汉语 / 我 / 学习 / 一点儿

2. 休息 / 想 / 我 / 一点儿

3. 书 / 看 / 一点儿 / 我

4. 做 / 今天 / 饭 / 一点儿 / 我 / 想

5. 运动 / 我 / 想 / 做 / 一点儿

  1. 我学习一点儿汉语。
  2. 我想休息一点儿。
  3. 我看一点儿书。
  4. 今天我想做一点儿饭。
  5. 我想做一点儿运动。

В последнем предложении естественно сочетание 做一点儿运动.

Упражнение 2. Ответь на вопросы

回答问题。 Отвечай полными предложениями, используя 一点儿 там, где это уместно.

你每天学习汉语吗？
— 学习。我每天学习一点儿汉语。
  1. 你每天学习汉语吗？学习多长时间？
  2. 你喜欢看书吗？每天看多少？
  3. 你今天想休息吗？想休息多长时间？
  4. 你每天做运动吗？做多少？
  5. 你今天做饭吗？做什么？
Дополнительный пример, если конструкция уже изучалась: 你今天累吗？—— 有一点儿累。我想休息一点儿。

4. Упражнения на 喜欢 и 会

喜欢 + глагол — любить что-либо делать.

我喜欢做饭。— Я люблю готовить.

会 + глагол — уметь что-либо делать.

我会做饭。— Я умею готовить.

8. Итоговое задание: 我的一个星期

任务：介绍你的一周。

Подготовь рассказ о своей неделе на китайском языке.

Что нужно включить в рассказ

  • Назвать минимум четыре дня недели.
  • Указать время минимум для четырёх действий.
  • Использовать не менее двух предложений с 先……然后…….
  • Использовать 喜欢 минимум два раза.
  • Использовать 会 минимум один раз.
  • Использовать 都 минимум один раз.
  • Использовать 一点儿 минимум один раз.
  • Включить не менее восьми словосочетаний из изученного списка.

План рассказа

第一部分：我的早上

  • 你几点起床？
  • 你几点吃早饭？
  • 你先做什么，然后做什么？

第二部分：我的白天

星期一到星期五，我每天早上七点起床，然后吃早饭。 八点我上班。中午十二点我吃午饭。下午六点我下班，然后回家。 晚上我先做饭，然后吃晚饭。我喜欢看书，也喜欢看电影。 我会做饭，但是不会开车。我每天学习一点儿汉语。 星期六我喜欢骑自行车，也喜欢散步。星期天我休息， 有时候看电视，有时候做运动。我和我的朋友都喜欢看电影。 星期天晚上我先做一点儿作业，然后睡觉。
